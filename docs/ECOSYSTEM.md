# Ecossistema Aerosuite

```
Aerosuite (marca / ops)
├── Precisou, Tá Pronto  → precisoutapronto.com.br     (hub de ferramentas)
└── MIRA          → search.aerosuite.com.br (busca B2B + CNPJ)
```

Repositórios:

- https://github.com/Aerosuitebr/precisoutapronto
- https://github.com/Aerosuitebr/mira
- https://github.com/Aerosuitebr/aerosuite

Integração hub → MIRA: variável `NEXT_PUBLIC_MIRA_URL` em `.env`.
