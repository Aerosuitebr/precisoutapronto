# Marca completa · Precisou, Tá Pronto

Na divulgação pública, use sempre “Precisou, Tá Pronto” como nome do produto.
Há várias marcas parecidas no mercado e
ruído semântico com “jato”.

## Forma canônica

| Uso | Texto |
|---|---|
| Nome | `Precisou, Tá Pronto` |
| Domínio | `precisoutapronto.com.br` |
| Primeira menção | Nome + domínio (ou link UTM) na mesma peça |
| Hashtag (se usar) | `#PrecisouTaPronto` |

## Regras por canal

1. **WhatsApp / Stories / Status:** a primeira linha (ou o fechamento) traz
   `Precisou, Tá Pronto`. O link já carrega o domínio.
2. **LinkedIn / Facebook / comunidades:** diga `Precisou, Tá Pronto` antes do benefício.
   Evite abrir só com o nome da ferramenta (“Calculadora de rescisão…”) sem marca.
3. **Diretórios / PH / MicroSaaS:** campo Nome = `Precisou, Tá Pronto` (nunca abreviação).
4. **Outreach / guest post:** assinatura `… do Precisou, Tá Pronto (precisoutapronto.com.br)`.
5. **Bio Instagram / TikTok:** linha 1 = `Precisou, Tá Pronto`.

## Anti-padrões

- “Resolva” sozinho
- Siglas isoladas como marca
- Link sem nenhuma menção textual à marca na peça
- Confundir com marcas de nome semelhante

## Checklist rápido antes de publicar

- [ ] Aparece `Precisou, Tá Pronto` no texto?
- [ ] Link aponta para `precisoutapronto.com.br` (com UTM)?
- [ ] Alguém que não conhece a marca entende o nome completo sem abrir o link?
